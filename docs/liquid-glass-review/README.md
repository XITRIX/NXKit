# UIKit / NXKit glass review — 28 October 2026

[Open the comparison index](comparison.html). Serve `docs/` from localhost if your browser blocks local images or links; all report assets are local and work offline.

The implementation follows measured UIKit framebuffer behavior. This iteration changes the regular-glass refraction shoulder and light-theme chroma/detail filtering, replaces automatic shadows, and shares neutral material sizing in heterogeneous containers. It adds the portable `LensView` extension and a Glass-gallery tab-bar/knob demonstration using the existing regular glass as its base. The native app instantiates `_UILiquidLensView` independently of system controls, so styles, resting fills, lift geometry and content can be compared directly.

Each report preserves geometry, masks, source/executable/archive hashes and residuals, including local regressions.

The [lens refraction viewer](../liquid-glass-lens/refraction/comparison.html) tests selected content crossing all four edges, sparse two-dimensional markers, colored backgrounds, and both themes. Its native session contains 38 validation scenes, 60 shader/source controls, 64 one-point line profiles and 15 private-configuration diagnostics, kept separate in the results. The live Demo uses portable icons and labels; native glyph assets are comparison inputs only. Its selected row stays beneath the moving lens and supplies the full optical input before the final capsule clip. The [research report](../liquid-glass-lens/research.md) records primary research, runtime-confirmed selectors, variant observations, authored native motion traces and license boundaries. Production contains independently implemented portable rendering, with no private UIKit calls or imported GPL source.

The new [background chromatic comparison](../liquid-glass-lens/chromatic/comparison.html) isolates the previously missing selection-lens background color transport across 29 scenes. Near-edge marker centroid error improves 1.044→0.378pt; perimeter RGB error improves 6.881→6.330/255, while chroma-only error slightly worsens 3.351→3.444 because spectral footprints still differ. Five regular-style controls remain byte-identical. The [motion replay](../liquid-glass-lens/motion/comparison.html) compares eight real UIKit gesture/interruption traces over 1,394 frames, with shared caller placement/lift/ancestor scale and separate local affine response. All eight improve over rigid geometry; tab reversal retains 0.872pt RMS and 3.793pt peak coordinate error. Fixed knobs use a separately labeled portable contact-input extension. The Demo enables both base glass and selection interaction, with actual tap/drag/cancel action tests and matching continuous punchout geometry.

Verification includes eleven retained raster suites: Layer, Corner, Material, Container, Shadow, Gallery, Interaction, Lens, LensTab, LensRefraction and LensMotion. These cover the final combined production archive; the previous selected-source report remains a labeled calibration snapshot. LensRefraction covers source-induced edge copies, near-rim disappearance, black-ink channel transport and corner reversal, fractional Retina texture alignment, source opacity/visibility and lazy label mutations. The final container correction is additionally checked against all 96 existing small-item join images, which remain byte-identical. Optical validation adds 762 measured matrix checks and 60 locality checks. The iOS Demo and material/container/shadow/lens regression executables build and link with the installed iOS 27.1 SDK; native captures run on iPadOS 27.0 build 24A434.

These are measured improvements, not pixel parity. Independent colored waves still show substantial optical-band residuals. Lifted lens caustics, spectral footprint widths, control-specific motion and native touch latency remain approximate or incomplete. The static native fixture's lift growth is supplied by its caller; it is not evidence of automatic inflation. End-to-end Metal/Dawn parity, GPU performance and physical iOS 27.2 remain unverified.
